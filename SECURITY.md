# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |
| < 0.1   | No        |

## Reporting a vulnerability

Report vulnerabilities **only** through GitHub private vulnerability reporting: Security tab → Report a vulnerability, or open https://github.com/swtormy-agents/local-pdf-tools-mcp/security/advisories/new

Do not open public issues for vulnerabilities.

## Response

We handle reports on a best-effort basis and aim to send an initial reply within 7 days.
